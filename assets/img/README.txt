Daftar gambar Fawnia (format .png)
===================================
Taruh semua foto di folder ini dengan nama PERSIS seperti di bawah.
Selama file belum ada, website otomatis menampilkan placeholder abu-abu.

Logo & hero
-----------
fawnia-logo.png      -> logo bulat (disarankan 512x512 px, transparan)
hero.png             -> foto utama di landing page (disarankan 800x1000 px)

Produk / bucket (rasio potret 4:5, disarankan 800x1000 px)
----------------------------------------------------------
bucket-1.png         -> Bucket Wisuda
bucket-2.png         -> Bucket Sweet
bucket-3.png         -> Bucket Custom
bucket-4.png         -> Gift Mini
bucket-5.png         -> Bucket Bunga Kering
bucket-6.png         -> Bucket Snack & Cake

Galeri (bebas, disarankan 800x1000 px)
--------------------------------------
galeri-1.png ... galeri-6.png

Catatan
-------
- Nama produk, harga, dan gambar bisa diganti lewat panel admin
  (pages/admin/login.html -> menu Produk / Galeri).
- Gambar yang di-upload dari admin disimpan di localStorage browser
  (maks 2 MB per gambar).
- File SVG lama (produk-*.svg, galeri-*.svg, hero.svg) sudah tidak dipakai
  dan boleh dihapus, atau dibiarkan sebagai cadangan.
